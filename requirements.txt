# UGV Rover Python dependencies.
#
# Raspberry Pi OS Trixie (Debian 13 / Python 3.13) and Bookworm (Python 3.11).
#
# The venv in scripts/setup.sh is created with --system-site-packages, so every
# compiled, hardware-bound library comes from apt and is NOT listed here:
#   python3-picamera2  python3-opencv     python3-numpy   python3-pil
#   python3-pygame     python3-pyaudio    python3-pyudev  python3-soundfile
# Mixing apt and pip copies of those (numpy/opencv especially) breaks the ABI,
# so keep them out of this file.
#
# Only pure-Python packages, and wheels that publish cp313/aarch64 builds,
# belong below. The previous version of this file was a full `pip freeze` of a
# Bookworm desktop image (thonny, PyQt5, torch, 300+ types-* stubs); it is kept
# as requirements.bookworm-freeze.txt for reference only.

# Web app
Flask>=3.0

python-socketio>=5.11
python-engineio>=4.8
simple-websocket>=1.0

# Config, serial, imaging helpers
PyYAML>=6.0.2
pyserial>=3.5
imutils>=0.5.4
imageio>=2.34

# Audio / speech (needs apt: espeak, portaudio19-dev)
pyttsx3>=2.90
sherpa-onnx>=1.12

# Vision (publishes cp313 aarch64 wheels)
depthai==2.30.0.0

# NOTE: ncnn is NOT listed here. Its recent wheels declare a dependency on
# opencv-python, which would pull a second (OpenCV 5) copy of cv2 into the venv
# and shadow apt's 4.10 that picamera2 is built against. scripts/setup.sh
# installs it with --no-deps instead; it imports fine without opencv-python.

# Notebooks under tutorials/
jupyterlab>=4.2
notebook>=7.2

# NOTE: mediapipe is intentionally absent. The only release installable on

# when mediapipe is missing; everything else works. On Python 3.11 you can add
# `mediapipe==0.10.9` to get them back.
